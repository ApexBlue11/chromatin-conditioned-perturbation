## OBJECTIVE
Test 93.3's H1: do enhancer-window accessibility (F_enh) and TF-regulon motif accessibility (F_reg) add a transferable,
cell-specific, drug-conditioned gene-local signal beyond promoter accessibility (F_prom) from the same samples? The test is T1's
linear hierarchical ridge, under 93.10's pre-registered rules.

## FUNCTION
- **`model/v9/chromatin_h1.py`:**
  - `install_c93(ctx, arrays)`: `ctx.enc['c93']`, where Ez[:, :, 0..2] = rank_normal of F_prom, F_enh and F_reg per (cell,
    feature) for c93-has cells, and 0 otherwise. `cov_dt` is the has dev-train cells and `cov_dev` the has dev cells, as
    `set_encodings` defines them.
  - `h1_builder` kinds:
    - B = [b, P]; C = [b, P, E, R]; Cp = [b, E, R];
    - N1 = [b, P, mean E, mean R], the means over fit cells with has excluding the held-out cell;
    - S = [b, P, (1 − λ) E + λ mean E, (1 − λ) R + λ mean R].
  - `cell_rule`: 5 → 4, 4 → 3, ≤ 3 → None.
  - `h1_reading` (93.10 item 6, cell counts over the measured dev cells only):
    - Δ all ≥ 0.004, or top ≥ 0.008;
    - centred ≥ 0.002;
    - C − B > 0 in ≥ k cells, and centred C − B > 0 in ≥ k;
    - S(C) − S(N1) ≥ 0.002, with C > N1 in ≥ k.
  - `run_h1`:
    - `cf.run_t1` on the specs B, C and N1, plus, when reported, Cp and S at λ ∈ {0.25, 0.5, 0.75};
    - rows of record = dev rows with level ≤ 2 in the measured dev cells;
    - reported: Cp vs B, each arm's LOCO, and the λ chosen by LOCO with its reading.
  - `calibrate(ctx, slot)`, slot 1 = F_enh, 2 = F_reg, 3 draws:
    - f\* = ρ·b + √(1 − ρ²)·(the slot column with genes permuted by rng 1000 + d);
    - the other columns are gene-permuted by rng 3000 + 10d + k;
    - cases null, P1 and P2 at {0.5, 2, 5} %, P3 at 5 %, and G at {2, 5} %, planted with `cp.plant` on the original y and
      μ^(−c).
  - `faults_and_mde`: VOID_null, VOID_P3, VOID_G, G_informative, and MDE at 3 of 3.
  - `main`: refuses on a c93 sha1 mismatch; writes a `not_run` output if k is None; runs both calibrations, then the real
    run; writes the marker. No reading is printed.
- **`model/v9/read_h1.py`:** the only reader. Refuses on a marker mismatch. The order is NOT RUN → VOID (any null, P3 or G
  pass, in either slot) → ADVANCES → DOES NOT ADVANCE, informative iff MDE_P1 ≤ 0.02 in both slots. A G note is added per
  slot, and the reported items are echoed.
- **`orchestration/make_chromatin93_h1_kernel.py`:** pins 10 files, among them `chromatin_h1.py` `763f0564` and the frozen
  `c93_features.npz` `23e12b9d`, plus the split bundle. Runs with `--draws 3` and writes `CHROMATIN93_H1_COMPLETE.json`.
