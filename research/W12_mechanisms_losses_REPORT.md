## 2. Technical Reimplementation Details (Per Technique)

### 1. Autofocus + Direction-Aware Loss (GEARS)
- **Mathematical Formulation:**
  $$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{autofocus}} + \lambda \mathcal{L}_{\text{direction}}$$
  $$\mathcal{L}_{\text{autofocus}} = \frac{1}{K}\sum_{k=1}^K |y_k - \hat{y}_k|^{2+\gamma}, \quad \mathcal{L}_{\text{direction}} = \frac{1}{K}\sum_{k=1}^K \left(\text{sign}(y_k - x_{\text{ctrl},k}) - \text{sign}(\hat{y}_k - x_{\text{ctrl},k})\right)^2$$
- **Implementation:** In PyTorch, set $\gamma = 2$ (which raises the error to the 4th power for extreme responders) and $\lambda = 0.1$ or $0.01$. Compute $\text{sign}(\cdot)$ on differential vectors with a small deadband $\epsilon = 0.1$ to avoid penalizing measurement noise near zero: `torch.sign(torch.clamp(delta, min=-eps, max=eps))`.

### 2. Adaptive Dynamic Loss Reweighting ($\mathcal{L}_{\text{adapt}}$, PertAdapt)
- **Mathematical Formulation:**
  $$\mathcal{L}_{\text{all}} = \frac{1}{N}\sum_{j=1}^N (\hat{y}_j - y_j)^2, \quad \mathcal{L}_{\text{DE}} = \frac{1}{|\mathcal{D}_c|}\sum_{j \in \mathcal{D}_c} (\hat{y}_j - y_j)^2$$
  $$\alpha_{\text{all}} = \text{stopgrad}\left(\frac{\mathcal{L}_{\text{all}} + \mathcal{L}_{\text{DE}}}{\mathcal{L}_{\text{all}}}\right), \quad \alpha_{\text{DE}} = \text{stopgrad}\left(\frac{\mathcal{L}_{\text{all}} + \mathcal{L}_{\text{DE}}}{\mathcal{L}_{\text{DE}}}\right)$$
  $$\mathcal{L}_{\text{adapt}} = \alpha_{\text{all}} \mathcal{L}_{\text{all}} + \alpha_{\text{DE}} \mathcal{L}_{\text{DE}}$$
- **Implementation:** Identify the top-$k$ DEGs ($k=20$ or $k=50$) per condition using control subtraction: `topk_idx = torch.topk(torch.abs(y - x_ctrl), k=k).indices`. Compute mean squared error over all genes and over `topk_idx`. Compute detached scaling factors using `.detach()` and take the weighted sum. This dynamically equalizes gradient magnitude between the 20 responsive genes and the 958 non-responsive genes.

### 3. Pearson Correlation Term on Differential Expression (XPert)
- **Mathematical Formulation:**
  $$\mathcal{L}_{\text{pcc}} = 1 - \frac{\sum_{j=1}^N (\Delta y_j - \overline{\Delta y})(\Delta \hat{y}_j - \overline{\Delta \hat{y}})}{\sqrt{\sum_{j=1}^N (\Delta y_j - \overline{\Delta y})^2}\sqrt{\sum_{j=1}^N (\Delta \hat{y}_j - \overline{\Delta \hat{y}})^2} + \epsilon}$$
  $$\mathcal{L}_{\text{total}} = \alpha \mathcal{L}_{\text{Huber}}(y, \hat{y}) + \beta \mathcal{L}_{\text{Huber}}(\Delta y, \Delta \hat{y}) + \gamma \mathcal{L}_{\text{pcc}}(\Delta y, \Delta \hat{y})$$
- **Implementation:** Center $\Delta y = y - x_{\text{ctrl}}$ and $\Delta \hat{y} = \hat{y} - x_{\text{ctrl}}$ across the gene dimension per sample ($dim=-1$), normalize by L2 norm plus $\epsilon = 10^{-7}$, compute the dot product, and subtract from 1. Combine with Huber loss on $\Delta y$ ($\beta = 1.0$) and set $\gamma = 0.5$.

### 4. Auxiliary Cell Classification Loss Removal on Cold-Cell
- **Mathematical Formulation:**
  $$\mathcal{L}_{\text{training}} = \mathcal{L}_{\text{recon}} + \lambda_{\text{cls}} \mathcal{L}_{\text{CE}}(\text{head}(z_{\text{cell}}), y_{\text{lineage}})$$
- **Implementation:** In code, set $\lambda_{\text{cls}} = 0.0$ or delete the auxiliary cell classification head entirely when training models aimed at unseen cell generalisation. Supervised cross-entropy forcing latent cell tokens to classify training cell IDs forces the encoder to store cell-specific batch and identity artifacts, directly harming out-of-distribution transfer.

### 5. Set-Level MMD Loss with Energy Distance Kernel (STATE)
- **Mathematical Formulation:**
  $$\text{MMD}^2(\hat{X}, X_{\text{tgt}}) = \frac{1}{S^2}\sum_{i,j} k(\hat{x}_i, \hat{x}_j) + \frac{1}{S^2}\sum_{i,j} k(x_{\text{tgt},i}, x_{\text{tgt},j}) - \frac{2}{S^2}\sum_{i,j} k(\hat{x}_i, x_{\text{tgt},j})$$
  $$k(u, v) = -\frac{1}{2}\|u - v\|_2$$
- **Implementation:** Using `geomloss.SamplesLoss(loss="energy")`, pass a predicted tensor of shape `[B, S, G]` and a target tensor of shape `[B, S, G]`, where $S$ is set size. For bulk L1000, this requires grouping multiple biological/technical replicates into synthetic batches of size $S \ge 4$.

### 6. RankCosine + MSE Hybrid Loss (CIGER / BADGER)
- **Mathematical Formulation:**
  $$P_y(i) = \frac{\exp(y_i / \tau)}{\sum_j \exp(y_j / \tau)}, \quad P_{\hat{y}}(i) = \frac{\exp(\hat{y}_i / \tau)}{\sum_j \exp(\hat{y}_j / \tau)}$$
  $$\mathcal{L}_{\text{RankCosine}} = \frac{1}{2}\left(1 - \frac{\sum_i P_y(i) P_{\hat{y}}(i)}{\sqrt{\sum_i P_y(i)^2}\sqrt{\sum_i P_{\hat{y}}(i)^2}}\right), \quad \mathcal{L}_{\text{hybrid}} = \text{MSE}(\hat{y}, y) + \lambda_{\text{rank}}\mathcal{L}_{\text{RankCosine}}$$
- **Implementation:** Apply softmax with temperature $\tau = 1.0$ across the 978 landmark genes for both true and predicted delta vectors. Compute cosine distance between the resulting probability distributions and add to standard MSE or Huber loss with weight $\lambda_{\text{rank}} = 0.5$.

### 7. Bypassing the Learned Basal State Encoder on Unseen Cells (TxPert)
- **Mathematical Formulation:**
  $$\text{Seen Cells:} \quad \hat{\mathbf{y}} = \mathbf{x} + \text{Decoder}(E_{\text{cell}}(\mathbf{x}) + E_{\text{drug}}(\mathbf{d}))$$
  $$\text{Unseen Cells (TxPert):} \quad \hat{\mathbf{y}} = \mathbf{x} + \text{Decoder}(E_{\text{drug}}(\mathbf{d})) \quad \text{or} \quad \hat{\mathbf{y}} = \mathbf{x} + g_\phi(\mathbf{z}_{\text{pert}})$$
- **Implementation:** During cold-cell evaluation (or via a trained skip connection), bypass the parameterized MLP/transformer encoder for unperturbed control expression $\mathbf{x}_{\text{ctrl}}$. Supply the raw unperturbed profile directly as the additive baseline anchor and only allow the neural network to predict a cell-agnostic or lineage-broad shift vector $\Delta$.

### 8. Adversarial Latent Disentanglement Removal (CPA / chemCPA / PerturBench)
- **Mathematical Formulation:**
  $$\text{Standard CPA:} \quad \min_{\theta} \max_{\psi} \mathcal{L}_{\text{recon}}(x, \hat{x}) - \lambda_{\text{adv}} \mathcal{L}_{\text{CE}}(\text{Discriminator}_\psi(z_{\text{basal}}), \text{cell\_id})$$
  $$\text{noAdv Variant:} \quad \min_{\theta} \mathcal{L}_{\text{recon}}(x, \hat{x})$$
- **Implementation:** Remove the adversarial discriminator network and the gradient reversal layer. Condition the decoder directly on the concatenation or sum of the cell latent representation and drug representation without penalizing mutual information via an adversary.

### 9. Dual-Branch Architecture (XPert)
- **Mathematical Formulation:**
  $$\mathbf{H}_{\text{pre}} = \text{TransformerEncoder}_{\text{pre}}(\mathbf{x}_{\text{ctrl}})$$
  $$\mathbf{H}_{\text{pert}} = \text{CrossAttention}(\mathbf{H}_{\text{pre}}, \text{DrugTokens})$$
  $$\hat{\mathbf{y}}_{\text{trt}} = \text{Head}_{\text{trt}}(\mathbf{H}_{\text{pert}}), \quad \hat{\mathbf{y}}_{\text{ctrl}} = \text{Head}_{\text{ctrl}}(\mathbf{H}_{\text{pre}}), \quad \hat{\Delta} = \hat{\mathbf{y}}_{\text{trt}} - \hat{\mathbf{y}}_{\text{ctrl}}$$
- **Implementation:** Construct two separate transformer branches: one processes the pre-perturbation control profile, the other processes the perturbed state through cross-attention with chemical and condition tokens. Supervise both endpoints ($\hat{y}_{\text{trt}}$ and $\hat{y}_{\text{ctrl}}$) as well as their difference ($\hat{\Delta}$).

### 10. Gene-Similarity Masked Cross-Attention (PertAdapt)
- **Mathematical Formulation:**
  $$\mathbf{A}_{i,j} = \begin{cases} 1 & \text{if } j \in \text{TopK\_Similar}(i \mid \text{GO Semantic Sim}) \\ 0 & \text{otherwise} \end{cases}$$
  $$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d}} + \mathbf{M}\right)\mathbf{V}, \quad \mathbf{M}_{i,j} = \begin{cases} 0 & \text{if } \mathbf{A}_{i,j} = 1 \\ -\infty & \text{if } \mathbf{A}_{i,j} = 0 \end{cases}$$
- **Implementation:** Precompute a $978 \times 978$ binary adjacency matrix using Wang semantic similarity over Gene Ontology terms, retaining the top 100 interaction partners per gene. Apply this matrix as an additive attention bias mask $\mathbf{M}$ in PyTorch multi-head attention: `attn_mask = (1.0 - A) * -1e9`.

### 11. Exposure-Conditioned Neural Operator (ExPO)
- **Mathematical Formulation:**
  $$\mathbf{e}(d, t) = \text{MLP}\left(\left[\sin(2^k \pi d), \cos(2^k \pi d), \sin(2^k \pi t), \cos(2^k \pi t)\right]_{k=0}^{L-1}\right)$$
  $$\mathbf{z}_{\text{out}} = \mathcal{F}^{-1}\left(\mathcal{R}_{\theta} \cdot \mathcal{F}(\mathbf{z}_{\text{gene}})\right) + \mathbf{e}(d, t)$$
- **Implementation:** Encode continuous dose ($d$ in $\mu\text{M}$) and time ($t$ in hours) using Fourier / sinusoidal position encodings across $L=8$ frequency octaves. Pass the resulting embedding into a 2-layer MLP to generate a continuous modulation vector that modulates gene embeddings via FiLM (Feature-wise Linear Modulation) scale and shift.

### 12. Pretrained Single-Cell Foundation Model Gene Embeddings (scGPT / scFoundation)
- **Mathematical Formulation:**
  $$\mathbf{E}_{\text{gene}} = \text{scGPT\_Embedding}(\text{Gene\_List}) \in \mathbb{R}^{978 \times D}$$
- **Implementation:** Load pre-extracted 512-dimensional gene token embeddings from scGPT or scFoundation. Replace randomly initialized gene token embeddings with these frozen or fine-tuned vectors. Linearly project to model hidden dimension $d_h$.

### 13. LLM Text-Derived Gene Embeddings (GenePT)
- **Mathematical Formulation:**
  $$\mathbf{E}_{\text{gene}} = \text{TextEmbedding}(\text{NCBI\_Summary}(\text{Gene})) \in \mathbb{R}^{978 \times 1536}$$
- **Implementation:** Fetch official NCBI gene text summaries for all 978 landmark genes. Extract 1536-dimensional embeddings using OpenAI `text-embedding-3-large` or `text-embedding-ada-002`. Save to an offline matrix `E_gene_pt.npy` and load into `nn.Embedding.from_pretrained(weights, freeze=True)`.

### 14. Pretrained Protein Language Model Embeddings (ESM-2)
- **Mathematical Formulation:**
  $$\mathbf{e}_g = \frac{1}{|T_g|}\sum_{t \in T_g} \left(\frac{1}{L_t}\sum_{i=1}^{L_t} \text{ESM-2}_{\text{residue}}(t, i)\right)$$
- **Implementation:** For each of the 978 landmark genes, retrieve its canonical UniProt amino acid sequence. Pass through `esm2_t33_650M_UR50D` or `esm2_t48_15B_UR50D`. Mean-pool over all amino acid residue embeddings to obtain a single 1280- or 5120-dimensional vector per gene. Project down to model dimension.

### 15. Pretrained 3D Molecular Encoder (Uni-Mol / Uni-Mol2)
- **Mathematical Formulation:**
  $$\mathbf{z}_{\text{drug}} = \text{UniMol}(\text{3D\_Conformer}(\text{SMILES})) \in \mathbb{R}^{512}$$
- **Implementation:** Generate 3D conformers for small molecules using RDKit ETKDG. Pass coordinates and atom types through the pretrained Uni-Mol SE(3)-equivariant transformer. Extract the `[CLS]` token as the global drug representation $\mathbf{z}_{\text{drug}}$.

### 16. Data Augmentation from Low-Concordance Experiments (DeepCE)
- **Mathematical Formulation:**
  $$\text{Loss} = \sum_{i \in \mathcal{D}_{\text{high}}} \mathcal{L}(y_i, \hat{y}_i) + \sum_{j \in \mathcal{D}_{\text{low}}} w_j \mathcal{L}(y_j, \hat{y}_j), \quad w_j = \max(0, \text{APC}_j)$$
- **Implementation:** Partition LINCS profiles into reliable ($\text{APC} \ge 0.7$) and unreliable ($\text{APC} < 0.7$). Instead of discarding the unreliable set, assign each sample a loss weight proportional to its Average Pearson Correlation score $w_j = \text{clamp}(\text{APC}_j, 0.0, 1.0)$. Sample from both sets during mini-batching.

### 17. Multi-Seed / Multi-Fold Model Ensembling
- **Mathematical Formulation:**
  $$\hat{\mathbf{y}}_{\text{ensemble}} = \frac{1}{M}\sum_{m=1}^M \hat{\mathbf{y}}_{\theta_m}$$
- **Implementation:** Train $M=5$ identical models using distinct random seeds (or the 5 cross-validation folds). At inference time, compute model forward passes independently and average predicted delta expression vectors before computing Pearson correlation.

### 18. Multi-Task Pretraining with Cell Viability / Growth Curves (MultiDCP)
- **Mathematical Formulation:**
  $$\mathcal{L}_{\text{multitask}} = \mathcal{L}_{\text{expression}}(\Delta y, \Delta \hat{y}) + \lambda_{\text{viab}} \sum_{t=1}^T (\hat{v}_t - v_t)^2$$
- **Implementation:** Add an auxiliary prediction head taking the pooled cell-drug latent state to output a 9-point dosage-viability curve. When viability data is present (from PRISM/GDSC), compute MSE on viability and backpropagate jointly with $\lambda_{\text{viab}} = 0.2$.

### 19. Replicate Denoising via MODZ Consensus Weighting (TranSiGen)
- **Mathematical Formulation:**
  $$w_i = \frac{\max\left(0, \sum_{j \neq i} \text{Spearman}(x_i, x_j)\right)}{\sum_k \max\left(0, \sum_{j \neq k} \text{Spearman}(x_k, x_j)\right)}, \quad x_{\text{MODZ}} = \sum_{i=1}^r w_i x_i$$
- **Implementation:** For replicate wells sharing the same (cell, compound, dose, time) coordinate, calculate the pairwise Spearman correlation matrix. Weight each replicate vector by the sum of its positive correlations to peer replicates, and compute the linear combination as the training target.

### 20. FlashAttention-2 / PyTorch SDPA with Varlen Attention
- **Mathematical Formulation:**
  $$\mathbf{O} = \text{FlashAttention-2}(\mathbf{Q}, \mathbf{K}, \mathbf{V}, \text{cu\_seqlens})$$
- **Implementation:** Replace standard PyTorch attention with `torch.nn.functional.scaled_dot_product_attention`. When varying sequence lengths exist, pack tensors into shape `[Total_Tokens, D]` and pass cumulative sequence length offsets (`cu_seqlens`) directly into FlashAttention-2 kernels to prevent computing attention on padding tokens.

### 21. Bfloat16 (bf16) Mixed Precision Training
- **Mathematical Formulation:**
  $$\text{Forward/Backward in BF16} \quad (\text{1 sign, 8 exponent, 7 mantissa}), \quad \text{Optimizer Step in FP32}$$
- **Implementation:** Wrap the training step in `with torch.autocast(device_type='cuda', dtype=torch.bfloat16):`. Eliminate `torch.cuda.amp.GradScaler` completely, as bf16's dynamic range eliminates underflow.

### 22. torch.compile (Inductor Operator Fusion)
- **Mathematical Formulation:**
  $$\text{FusedKernel}(\mathbf{x}) = \text{LayerNorm}(\mathbf{x} + \text{Dropout}(\text{GELU}(\mathbf{W}\mathbf{x})))$$
- **Implementation:** Run `model = torch.compile(model, mode="reduce-overhead")` after model initialization. Ensure input batch sizes are constant or compile with `dynamic=True` to avoid repeated JIT trace compilation.

### 23. Sequence Packing for Variable-Length Atom Sequences
- **Mathematical Formulation:**
  $$\mathbf{X}_{\text{packed}} = \left[\mathbf{x}_1^{(1)}, \dots, \mathbf{x}_{L_1}^{(1)}, \mathbf{x}_1^{(2)}, \dots, \mathbf{x}_{L_2}^{(2)}, \dots\right] \in \mathbb{R}^{\sum L_i \times D}$$
- **Implementation:** Concatenate unpadded atom token sequences across the mini-batch into a single 1D tensor along the sequence dimension. Track `cu_seqlens = [0, L_1, L_1+L_2, \dots]`. Pass `cu_seqlens` to attention and dense layers without inserting padding tokens.

## 3. Judgement: The 8 Techniques Most Likely to Improve UNSEEN-CELL Accuracy

The following 8 techniques are selected and ranked based on concrete ablation evidence, architectural suitability for a 978-landmark bulk LINCS transformer ("v9"), and their targeted impact on **held-out cell line transfer**:

```
Rank 1: Bypassing / Ablating the Learned Basal State Encoder on Cold Cells (TxPert / V9 Noise Cancellation Diagnosis)
Rank 2: Removing the Auxiliary Cell-Lineage Classification Loss (XPert Ablation Table R13)
Rank 3: Adaptive Dynamic Loss Reweighting DEGs vs All Genes (PertAdapt L_adapt)
Rank 4: Multi-Seed / Cross-Fold Prediction Ensembling (5-Fold Averaging)
Rank 5: Dropping Atom-to-Atom Attention & Atom Tokens in Favor of Global Uni-Mol (RESULTS §74 / Bai et al. 2026)
Rank 6: Continuous Fourier Exposure Conditioning (ExPO Operator Formulation)
Rank 7: Replicate-Concordance Loss Weighting / TAS Gating (Noise-Robust Training)
Rank 8: Replacing Random Gene Tokens with Static Pretrained GenePT / Text Embeddings (GenePT / Ahlmann-Eltze)
```

### Ranked Rationales

1. **Bypassing / Ablating the Learned Basal State Encoder on Cold Cells (TxPert / V9 Noise Cancellation Diagnosis)**  
   *Reasoning:* TxPert demonstrated that using no learned basal state encoder ($\hat{y} = x_{\text{ctrl}} + g_\phi(z_{\text{pert}})$) is the single most effective choice for cross-cell-line transfer because learned encoders overfit the manifold of seen cell lines, whereas preserving the empirical unperturbed control profile directly anchors the unseen cell's transcriptional state without latent distortion.

2. **Removing the Auxiliary Cell-Lineage Classification Loss (XPert Ablation Table R13)**  
   *Reasoning:* XPert’s controlled ablation on LINCS Cold-Cell (Table R13) proved that removing cell classification supervision (`w/o cls_loss`) directly improves cold-cell $R^2$ from 0.177 to 0.189 (+6.8% relative) and Pearson from 0.434 to 0.436, because forcing cell tokens to classify training cell identities explicitly memorizes seen-lineage noise patterns.

3. **Adaptive Dynamic Loss Reweighting DEGs vs All Genes (PertAdapt $\mathcal{L}_{\text{adapt}}$)**  
   *Reasoning:* In LINCS L1000, unperturbed genes dominate 95% of each row; PertAdapt’s detached dynamic loss normalization prevents gradient dilution from invariant genes and forced a +0.032 to +0.057 MSE drop across foundation backbones, directly optimizing the model for the differentially expressed genes that define the test metric ($PCC_{\Delta, \text{DEG}}$).

4. **Multi-Seed / Cross-Fold Prediction Ensembling (5-Fold Averaging)**  
   *Reasoning:* Across every competitive benchmark and Kaggle perturbation competition, averaging predictions across 5 independent seeds or cross-validation folds reliably delivers a +0.015 to +0.025 Pearson gain on held-out test rows by cancelling uncorrelated variance and pseudo-replicate prediction noise at zero training architecture risk.

5. **Dropping Atom-to-Atom Attention & Atom Tokens in Favor of Global Uni-Mol (RESULTS §74 / Bai et al. 2026)**  
   *Reasoning:* Bai et al. (2026) proved that seven L1000 models fail to utilize chemical features effectively, and this project's own measurements (§61.7, §74) showed atom tokens actively degrade generalization on unseen compounds (-0.018 Pearson); replacing multi-atom tokens with a single global Uni-Mol token removes memorized scaffold noise while slashing attention complexity.

6. **Continuous Fourier Exposure Conditioning (ExPO Operator Formulation)**  
   *Reasoning:* LINCS cell lines are probed across non-standardized dose-time combinations; ExPO demonstrated that replacing discrete dose/time token bins with continuous Fourier/sinusoidal frequency modulations yields superior out-of-distribution transfer across exposure coordinates ($t, d$) on leave-cell-line-out splits (Spearman 0.44 vs DeepCE 0.40).

7. **Replicate-Concordance Loss Weighting / TAS Gating (Noise-Robust Training)**  
   *Reasoning:* DeepCE demonstrated that weighting training instances by their internal replicate consistency (Average Pearson Correlation / Transcriptional Activity Score) prevents high-noise, un-reproducible LINCS plates from injecting false perturbation signals into gradient updates, increasing generalizable correlation from 0.4907 to 0.5014.

8. **Replacing Random Gene Tokens with Static Pretrained GenePT / Text Embeddings (GenePT / Ahlmann-Eltze)**  
   *Reasoning:* Ahlmann-Eltze et al. (Nature Methods 2025) showed that providing informative static gene embeddings yields a consistent edge over random initialization; GenePT provides rich biological semantics (functional pathways, co-regulation) across the 978 landmarks without the computational overhead or training instability of scRNA-seq foundation models.
